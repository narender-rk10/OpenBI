Agent 1 - FinanceSQL
----------------------------------------------------------
Name:        FinanceSQL
Description: SQL agent across PostgreSQL finance/retail and MySQL marketing/HR

Prompt:
You are a senior financial data analyst. Generate accurate SQL queries across multiple databases.

PostgreSQL financedb tables:
  funds(fund_id, fund_name, ticker, asset_class, management_fee_bps)
  daily_nav(nav_id, fund_id, trade_date, nav_per_share, total_aum, daily_net_flow)

  client_transactions(tx_id, tx_date, portfolio_id, fund_id, tx_type, amount)
  benchmark_returns(return_id, fund_id, period_date, fund_return_pct, benchmark_return_pct, alpha_bps)

PostgreSQL retaildb tables:
  customers(customer_id, name, email, city, customer_type)
  orders(order_id, customer_id, order_date, status)
  order_items(order_item_id, order_id, product_id, quantity, unit_price)
  products(product_id, name, category, price_usd)

MySQL marketingdb tables:
  marketing_campaigns(campaign_id, campaign_name, channel, target_client_type)
  client_acquisitions(acquisition_id, report_date, campaign_id, marketing_spend, new_leads, converted_clients, new_aum_acquired)

MySQL hrdb tables:
  departments(department_id, name, location)
  employees(employee_id, department_id, full_name, title, salary_usd, hire_date)
  attendance(att_id, emp_id, att_date, status)

Rules:
- Show monetary values in millions (M) or billions (B) with 2 decimal places
- For MySQL use DATE_FORMAT, YEAR(), MONTH()
- For PostgreSQL use TO_CHAR, DATE_TRUNC, EXTRACT
- Always ORDER BY relevant column

Skills: Add ALL 4 connections as text2sql
  - Finance Portfolio DB    -> tables: funds, daily_nav, portfolios, client_transactions, benchmark_returns
  - Retail E-Commerce DB    -> tables: customers, orders, order_items, products
  - Marketing Campaigns MySQL -> tables: marketing_campaigns, client_acquisitions
  - HR Operations MySQL     -> tables: departments, employees, attendance

Dashboard Name: Finance Analytics - Fund Portfolio Dashboard

----------------------------------------------------------
Widget 1 - Chart
----------------------------------------------------------
Title:      Daily NAV Trend - All Funds 2024
Type:       Chart
Connection: Finance Portfolio DB
SQL:
SELECT f.fund_name,
       TO_CHAR(DATE_TRUNC('month', dn.trade_date), 'YYYY-MM') AS month,
       ROUND(AVG(dn.nav_per_share), 4) AS avg_nav
FROM daily_nav dn
JOIN funds f ON dn.fund_id = f.fund_id
WHERE dn.trade_date >= '2024-01-01' AND dn.trade_date <= '2024-12-31'
GROUP BY f.fund_name, DATE_TRUNC('month', dn.trade_date)
ORDER BY month, f.fund_name

----------------------------------------------------------
Widget 2 - Chart
----------------------------------------------------------
Title:      Total AUM by Fund (Latest)
Type:       Chart
Connection: Finance Portfolio DB
SQL:
SELECT f.fund_name,
       ROUND(dn.total_aum / 1000000000.0, 2) AS aum_billions
FROM daily_nav dn
JOIN funds f ON dn.fund_id = f.fund_id
WHERE dn.trade_date = (SELECT MAX(trade_date) FROM daily_nav)
ORDER BY aum_billions DESC

Widget 11 - Table

Title:      Fund Summary - Latest NAV

SELECT f.fund_name, f.ticker, f.asset_class,

----------------------------------------------------------
Widget 12 - Table
----------------------------------------------------------
Title:      Marketing ROI by Campaign
Type:       Table
Connection: Marketing Campaigns MySQL
SQL:
SELECT mc.campaign_name, mc.channel,
       ROUND(SUM(ca.marketing_spend) / 1000000.0, 2) AS spend_M,
       ROUND(SUM(ca.new_aum_acquired) / 1000000.0, 0) AS aum_acquired_M,
       SUM(ca.converted_clients) AS clients,
       ROUND(SUM(ca.new_aum_acquired) / SUM(ca.marketing_spend), 0) AS roi_ratio
FROM client_acquisitions ca
JOIN marketing_campaigns mc ON ca.campaign_id = mc.campaign_id
GROUP BY mc.campaign_name, mc.channel
ORDER BY roi_ratio DESC

----------------------------------------------------------
Widget 13 - Table
----------------------------------------------------------
Title:      HR Salary by Department
Type:       Table
Connection: HR Operations MySQL
SQL:
SELECT d.name AS department,
       COUNT(e.employee_id) AS headcount,
       ROUND(AVG(e.salary_usd), 0) AS avg_salary,
       ROUND(MIN(e.salary_usd), 0) AS min_salary,
       ROUND(MAX(e.salary_usd), 0) AS max_salary
FROM employees e
JOIN departments d ON e.department_id = d.department_id
GROUP BY d.name
ORDER BY avg_salary DESC

----------------------------------------------------------
Widget 14 - Table
----------------------------------------------------------
Title:      Retail Top Products by Revenue
Type:       Table
Connection: Retail E-Commerce DB
SQL:
SELECT p.name AS product, p.category,
       SUM(oi.quantity) AS units_sold,
       ROUND(SUM(oi.quantity * oi.unit_price), 2) AS revenue
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
GROUP BY p.name, p.category
ORDER BY revenue DESC
LIMIT 10
